# 06 AI 接口设计

所有 AI 调用先写 `ai_request`（kind、input、output、model、prompt_version、latency_ms、cost_cny、status），再把结构化结果写入专用表。AI 只给建议：报价要经过毛利规则/审批，工时定额要人工确认。场景脚本中 AI 输出为假数据（model = `mock`）。

## A1 读图报价 `drawing_quote`

**输入**
```json
{"type":"object","required":["drawing_uri","qty"],
 "properties":{"drawing_uri":{"type":"string"},"customer":{"type":"string"},"qty":{"type":"number","minimum":1}}}
```
**输出**
```json
{"type":"object","required":["material_code","stock_diameter_mm","stock_length_mm","confidence"],
 "properties":{
  "material_code":{"type":"string","description":"材质，如 45#、SUS304、6061"},
  "stock_diameter_mm":{"type":"number"},"stock_length_mm":{"type":"number"},
  "finished_weight_kg":{"type":"number"},"plated_area_dm2":{"type":"number"},
  "tightest_tolerance_mm":{"type":"number"},"surface_treatment":{"type":"string"},"heat_treatment":{"type":"string"},
  "similar_item_id":{"type":["integer","null"],"description":"历史相似件，用于套用 BOM/工艺"},
  "confidence":{"type":"number","minimum":0,"maximum":1}}}
```
**落表**：`fn_ai_record_drawing_quote(input, output)` → `ai_request` + `ai_drawing_feature`；`quotation.ai_request_id` 关联。成本由 `fn_quote_cost` 用相似件 BOM/工艺 + `ref_param` 计算（AI 不直接给价格，避免“幻觉价”）。置信度 < 0.7 时前端强制人工确认特征（规则建议）。

## A2 委外对账单核对 `subcon_statement_check`

**输入**：外协厂对账单照片 → OCR/多模态模型抽取为：
```json
{"type":"object","required":["period","lines"],
 "properties":{"period":{"type":"string","pattern":"^\\d{4}-\\d{2}$"},
  "lines":{"type":"array","items":{"type":"object","required":["order_no"],
    "properties":{"order_no":{"type":"string"},"sent_qty":{"type":"number"},"good_qty":{"type":"number"},
                  "defect_qty":{"type":"number"},"amount":{"type":"number"}}}}}}
```
**输出（SQL 侧计算）**：`ai_subcon_check_line(field, statement_value, system_value, diff, verdict)`，verdict ∈ match / mismatch / missing_in_system / missing_in_statement。系统值取自 `subcontract_order` 与 `subcontract_settlement.payable_amount`（已扣超定额损耗）。
**函数**：`fn_ai_check_subcon_statement(supplier_id, statement_json)`。

## A3 完工复盘修正工时定额 `cost_review`

**输入**：`{"work_order_id": 123}`
**输出**（逐工序）：
```json
{"type":"array","items":{"type":"object",
 "properties":{"routing_op_id":{"type":"integer"},"quoted_hours":{"type":"number"},
  "actual_hours_per_unit":{"type":"number"},"proposed_hours":{"type":"number"}}}}
```
**算法（当前版本为规则模型 `rule:ewma`）**：实际单件工时 = Σ非返工报工工时 / Σ合格数；建议定额 = α×实际 + (1−α)×原定额，α = `ex_std_hours_learning_rate`（示例 0.7）。后续可替换为考虑设备、批量、材质的回归模型，接口不变。
**落表**：`ai_cost_review`；`fn_apply_cost_review(id)` 人工确认后写回 `routing_operation.std_hours`。

## A4 交期预测 `leadtime_predict`

**输入**：`{"sales_order_id": 1, "baseline_finish": "2026-11-05"}`（基线来自 `fn_schedule_finite` 有限能力排产）
**输出**：
```json
{"type":"object","required":["delay_days"],
 "properties":{"delay_days":{"type":"integer"},"p90_delay_days":{"type":"integer"},"risk_note":{"type":"string"}}}
```
特征建议：外协厂历史延误、设备负荷率、在制品返工率、物料到货延误。
**落表**：`fn_ai_leadtime(so, output)` → `ai_leadtime_prediction(baseline_finish, predicted_finish, p90_finish, risk_note)`。
