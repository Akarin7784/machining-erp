# 01 业务流程

每条流程列出参与者、关键函数和数据库层保证。函数位于 `db/functions/`。

## F01 读图报价与低毛利审批

```mermaid
sequenceDiagram
  actor 销售
  participant AI as AI 读图服务
  participant DB as PostgreSQL
  actor 经理
  销售->>AI: 上传图纸 PDF/DXF + 数量
  AI-->>销售: 材质/坯料尺寸/成品重/镀层面积/公差/相似件
  销售->>DB: fn_ai_record_drawing_quote(input, output)
  销售->>DB: INSERT quotation / quotation_item
  销售->>DB: fn_quote_cost(行) 多层 BOM × 工艺路线 × ref_param
  DB-->>销售: 材料/机加工/热处理/表面处理/外购/特殊费用, ×管理费系数, 建议价
  销售->>DB: 改售价, fn_quote_submit()
  alt 毛利率 ≥ 底线
    DB-->>销售: approved(系统自动)
  else 毛利率 < 底线
    DB-->>经理: pending_approval
    经理->>DB: fn_quote_decide(批准/驳回, 意见)
  end
```

报价公式（依据库卡竞价公告的计价口径）：
`单件成本 = (材料kg价×毛重 + Σ工时×设备费率 + 热处理费 + 表面处理费 + 外购件 + 特殊费用) × 管理费系数`，
`建议价 = 单件成本 / (1 − 毛利底线)`。

## F02 订单 → MRP → 工单 → 排产

```mermaid
sequenceDiagram
  participant SO as 销售订单
  participant MRP as fn_run_mrp
  participant WO as 工单
  participant SCH as fn_schedule_finite
  SO->>MRP: 订单行(数量-已发)
  MRP->>MRP: 递归展开 BOM(含损耗率), 扣现存量
  MRP->>WO: 自制件: 按层级建工单, 子工单挂父工单, 复制工艺路线, 下达
  MRP-->>SO: 外购件: mrp_line(action=buy) → 采购
  SCH->>WO: 子工单先排, 父工单在子工单完工后开工
  SCH->>SCH: 每台设备每天占用 ≤ hours_per_day, 周日休息, 委外按外协周期顺延
```

## F03 采购 → 来料检 → 入库 → 进项发票

```mermaid
stateDiagram-v2
  [*] --> draft
  draft --> inspecting: fn_po_receive 到货
  inspecting --> posted: fn_incoming_inspection 全部行检验后 fn_receipt_post
  posted --> cancelled
```
合格品按 `含税单价/(1+税率)` 入库（借 原材料 贷 应付暂估）；不合格品不入库并累计到 `rejected_qty`。进项发票 `fn_purchase_invoice`：借 应付暂估 + 进项税，贷 应付账款，同时写应付流水。

## F04 生产：发料 / 报工 / 工序检 / 返工 / 完工

```mermaid
sequenceDiagram
  actor 操作工
  participant JC as job_card(只增不改)
  participant OP as wo_operation
  participant COST as wo_cost_entry
  participant GL as 总账
  操作工->>JC: 扫码报工(合格, 报废, 工时)
  JC->>JC: BEFORE: 工单状态, 图纸版本必须生效, 数量≤可报数, 算计件工资/机时成本
  JC->>OP: AFTER: 完工数+, 下一道工序投入数+
  JC->>COST: 人工/机时(返工单列 rework)
  JC->>GL: 借 生产成本 贷 应付职工薪酬/制造费用
  Note over OP: 工序检 fn_process_inspection: 返工数退回本工序 rework_pending, 下道工序投入数扣减
  操作工->>JC: 返工报工 is_rework=true(不计件)
```

工单数量守恒：`本工序可报 = 投入 − 完工 − 报废 − 待返工`。成品检 `fn_final_inspection` 后才能 `fn_wo_receive`，入库金额 = 工单累计成本按剩余可入库数分摊。

## F05 委外加工（调质、镀铬）

```mermaid
sequenceDiagram
  participant WO as 工单工序(委外)
  participant SC as subcontract_order
  participant SUP as 外协厂
  participant AP as 应付
  WO->>SC: fn_subcon_create 快照单价、损耗定额、在制品单件成本
  SC->>SUP: fn_subcon_send 发出(≤可发数)
  SUP-->>SC: fn_subcon_receive 分批回料(合格, 不良) + 回料检验
  SC->>SC: fn_subcon_settle 短少=发出−合格−不良, 超定额=(短少+不良)−发出×定额
  SC->>AP: 应付=加工费(合格×基数×单价) − 超定额×在制品单件成本
  SUP-->>SC: 对账单照片 → AI 识别 → fn_ai_check_subcon_statement 标差异
```

## F06 图纸变更（客户中途改图）

```mermaid
stateDiagram-v2
  [*] --> draft
  draft --> released: fn_release_drawing（同物料旧版自动 superseded）
  released --> superseded
```
`fn_change_drawing` 发布新版、把未完结订单行和工单切到新版、写 ECN（受影响在制品数、处置意见）。之后按旧版报工会被 `trg_job_card_before` 拒绝（EP004）。

## F07 余料（边角料）

领料后按长度/直径/重量登记 `fn_return_remnant`：按本工单领料均价入余料仓，冲减工单材料成本（`remnant_credit`）。其他工单可用 `fn_reuse_remnant` 再领用，状态 available → reused，不能重复领用。

## F08 发货、开票、收款、退货

```mermaid
sequenceDiagram
  participant SO as 销售订单
  participant DN as 发货单
  participant INV as 发票
  participant AR as 应收流水
  SO->>DN: fn_deliver(可部分发货, ≤订单数)
  DN->>INV: fn_sales_invoice(专票/普票, 价税分离)
  INV->>AR: +价税合计
  Note over AR: fn_payment(receive) 按发票核销, 剩余为预收
  DN->>DN: fn_sales_return → 退货单 posted
  DN->>INV: 触发器: 红字发票(负数)
  INV->>AR: 冲减原发票应收
```

## F09 多工厂调拨

`fn_transfer_ship`：调出仓 → 在途仓（借 在途物资 贷 存货）；`fn_transfer_receive`：在途 → 调入仓。金额随货转移，在途科目最终为 0。

## F10 月结

1. `fn_customer_statement(客户, 期间)`：期初、本期发票/红票/收款、期末、已发货未开票。
2. `fn_close_period(期间)`：检查试算平衡、应收/应付总账与明细账一致，然后关账；关账后该期间不能再过账。

## F11 完工复盘

`v_order_cost_actual` 汇总订单实际成本（材料−余料冲减、人工、机时、委外−扣款、返工；半成品结转不重复计入），与报价单件成本对比。`fn_cost_review` 按 `新定额 = α×实际 + (1−α)×原定额` 给出建议，`fn_apply_cost_review` 人工确认后写回工艺路线，下一次 `fn_quote_cost` 自动使用。
